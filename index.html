📘 Instruções para Cadastro Manual (Um a Um) — Área Exclusiva Admin
  1. Nome do Produto: Digite o título completo do item (ex: Perfume Sauvage Elixir 100ml ou Kit 5 Camisetas Básicas).
  2. Sinal Fixo PIX (R$): Informe o valor cobrado via PIX na reserva inicial de cada vaga (padrão 20 para R$ 20,00). Use ponto para centavos (ex: 25.50).
  3. Valor Cheio (R$): Informe o preço final total do produto. Quando o Box atingir 10 peças, o sistema calculará automaticamente o restante via PIX (Valor Cheio - Sinal).
  4. Categoria: Informe o grupo do produto (ex: Perfumes, Eletrônicos, Moda) para criar filtros automáticos na loja.
  5. Clique em Salvar — ele aparecerá imediatamente no catálogo da Nexxus Oficial BR no Box #1 (0/10).

📗 Instruções para Cadastro em Lote (+100 Produtos) — Área Exclusiva Admin

Para cadastrar dezenas ou centenas de produtos de uma só vez, siga exatamente este padrão:

  • Coloque 1 produto por linha separando os 4 campos por ponto e vírgula (;).
  • Ordem obrigatória dos campos: Nome do Produto; Valor do Sinal; Valor Cheio; Categoria
  • Use ponto (.) para centavos e não coloque "R$" antes dos números.
  • Exemplo válido:
    Perfume Bleu 100ml; 20.00; 580.00; Perfumes
    Relógio Esportivo Pro; 20.00; 240.00; Acessórios
    Fone Sem Fio ANC; 20.00; 190.00; Eletrônicos
